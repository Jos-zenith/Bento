# CASME II Micro-Expression Classification - Panjaayathu Engine\n\n## Overview\n\nThis is a **production-ready PyTorch implementation** for micro-expression classification on the CASME II dataset. It integrates:\n\n- **3D-CNN-LSTM architecture** with EfficientNet-B0 spatial encoder\n- **Optical flow preprocessing** for capturing micro-movements\n- **Transfer learning** from macro-expression models (ImageNet pre-trained weights)\n- **Wellness engagement scoring** for relationship intelligence applications\n- **Real-time inference** pipeline for video processing\n\n### Key Features\n\n✅ **Advanced Architecture**: 3D spatio-temporal feature extraction + bidirectional LSTM\n✅ **Transfer Learning**: Pre-trained EfficientNet-B0 backbone fine-tuned on CASME II\n✅ **Optical Flow**: Lucas-Kanade and Farneback methods for motion capture\n✅ **Data Augmentation**: Spatial and temporal augmentation for robustness\n✅ **Weighted Classification**: Handles class imbalance in micro-expressions\n✅ **Wellness Scoring**: W(u) = α*A(u) + β*S(u) + γ*C(u) integration\n✅ **Inference Pipeline**: Batch, single, video, and directory inference\n✅ **TensorBoard Logging**: Monitor training in real-time\n\n---\n\n## Installation\n\n### Requirements\n- Python 3.8+\n- CUDA 11.0+ (for GPU acceleration)\n- 8GB+ VRAM recommended\n\n### Setup\n\n```bash\n# Install dependencies\npip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118\npip install opencv-python pandas openpyxl numpy scikit-learn tensorboard\n\n# Optional: For advanced visualization\npip install matplotlib seaborn scikit-image\n```\n\n---\n\n## Project Structure\n\n```\nCASME II/\n├── config.py              # Verify dataset labels are loaded correctly\n2. Check optical flow computation (look for zeros)\n3. Increase `FREEZE_BACKBONE_EPOCHS` for transfer learning\n4. Try different learning rates: [1e-5, 1e-4, 1e-3]\n5. Ensure data augmentation is enabled\n\n### Issue: Overfitting\n\n**Solutions:**\n- Increase dropout rates\n- Reduce model complexity (use 3D-CNN instead of 3D-CNN-LSTM)\n- Add more data augmentation\n- Use early stopping (implemented)\n\n---\n\n## Advanced Usage\n\n### Custom Emotion Classes\n\nModify in `config.py`:\n```python\nNUM_CLASSES = 7\nCLASS_MAPPING = {\n    'Happiness': 0,\n    'Surprise': 1,\n    'Disgust': 2,\n    'Sadness': 3,\n    'Fear': 4,\n    'Repression': 5,\n    'Others': 6\n}\n```\n\n### Custom Wellness Weights\n\n```python\ncalculator = WellnessScoreCalculator(\n    alpha=0.6,  # Emphasize affective\n    beta=0.2,\n    gamma=0.2,\n    emotion_valence={...},  # Custom valence mapping\n    dharma_keywords=[...],   # Custom cultural keywords\n    seva_keywords=[...]\n)\n```\n\n### Batch Video Processing\n\n```python\nfrom inference import MicroExpressionPredictor\n\npredictor = MicroExpressionPredictor(\"checkpoints/best_model.pth\")\n\n# Process all sequences in directory\nresults = predictor.predict_directory(\n    \"Cropped/Cropped/sub01/\",\n    pattern=\"*.jpg\"\n)\n\nfor r in results:\n    print(f\"{r['sequence']}: {r['emotion']} ({r['confidence']:.2%})\")\n```\n\n---\n\n## References\n\n1. **CASME II Dataset**: [Paper](http://casme.psych.ac.cn/)\n   -
